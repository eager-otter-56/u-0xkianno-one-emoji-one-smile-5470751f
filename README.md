# One Emoji, One Smile

Entry for the make.fun bounty "One Emoji, One Smile". The program
writes exactly one emoji to `entry.txt` in `MAKEFUN_OUTPUT_DIR`
(default `/output`): 🌞, the sun with face — warm and friendly at
first glance, read the same way by a stranger of any age or
background, and a deliberate pick rather than the default smiley.

Run it with:

```sh
python3 main.py
```
